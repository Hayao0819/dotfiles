## 記載方針

設定の選び方、操作手順、リポジトリ固有の注意点だけを簡潔に記載します。
作業履歴、調査ログ、マシンの一時的な状態、パッケージ一覧の転記は残しません。
設定の詳細はソースを参照し、一般的な解説は公式資料へリンクします。
