# Build system & 0.15→0.16 deltas

## build.zig — the module API (0.15)

The flat `addExecutable` signature is gone; wire everything through a module:

```zig
pub fn build(b: *std.Build) void {
    const target = b.standardTargetOptions(.{});
    const optimize = b.standardOptimizeOption(.{});

    const exe = b.addExecutable(.{
        .name = "app",
        .root_module = b.createModule(.{
            .root_source_file = b.path("src/main.zig"),
            .target = target,
            .optimize = optimize,
            .imports = &.{
                .{ .name = "gtk4", .module = b.dependency("gobject", .{}).module("gtk4") },
            },
        }),
    });
    b.installArtifact(exe);

    const tests = b.addTest(.{ .root_module = b.createModule(.{
        .root_source_file = b.path("src/test_main.zig"),
        .target = target,
        .optimize = optimize,
    }) });
    const run_tests = b.addRunArtifact(tests);
    b.step("test", "Run tests").dependOn(&run_tests.step);
}
```

Wire imports and links via `exe.root_module.*`, not the artifact.

## build.zig.zon

```zig
.{
    .name = .app,                      // a bare enum literal, not a string (0.14+)
    .version = "0.1.0",
    .minimum_zig_version = "0.15.2",
    .fingerprint = 0xbdbefad86a91dcfd, // mandatory; generated by `zig init`/`zig fetch --save`
    .dependencies = .{
        .gobject = .{ .url = "...", .hash = "...", .lazy = false },
    },
    .paths = .{""},
}
```

Never copy a `.fingerprint` from another project — it identifies yours. Add
dependencies with `zig fetch --save <url>`; mark heavy optional deps `.lazy = true`.

## 0.15.2 → 0.16.0 deltas a reviewer must know

The project is held at 0.15.2 (a dep still emits `@Type`, removed in 0.16). If/when
it moves, these change:

- **I/O deletions:** `GenericReader`, `AnyReader`, `FixedBufferStream`,
  `GenericWriter`, `null_writer`, `CountingReader` are **deleted** in 0.16.
- **fmt:** custom `format` is now `format(self, writer: *std.Io.Writer)
  std.Io.Writer.Error!void` (no format-string/options arg); print a formattable
  value with `{f}`; new `{t}` (tag/error name) and `{b64}`.
- **async** returns as the `std.Io` library interface (`Future`, `io.async`,
  `io.concurrent`, `.await`, `.cancel`) — not keywords.
- **`@cImport` is deprecated** → `addTranslateC` in the build system.
- **`@Type` removed** (the exact reason for the 0.15.2 pin).

## Tooling

- `zig build` / `zig build test` / `zig build -Dtarget=...` for cross-compilation
  (no external toolchain needed).
- `zig fmt` / `zig fmt --check` — whitespace only.
- Pin the compiler (gp-wrapper pins 0.15.2 in `build.zig.zon`, the Nix flake via
  zig-overlay, and CI via `setup-zig`) so every environment matches — do the same.
